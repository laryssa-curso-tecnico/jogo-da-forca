# Jogo da Forca

O Jogo da Forca é uma aplicação interativa em que o jogador deve descobrir uma palavra escolhendo letras. A cada tentativa, a aplicação atualiza o andamento da partida e a pontuação.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Desenvolvimento

Projeto desenvolvido individualmente durante o curso técnico, com orientação e apoio do professor.
